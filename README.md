# Haven Builder Scripts

Repositório de scripts e templates para automações do **Haven Builder** — sistema 100% autônomo de vendas e implementação de automações.

## Estrutura
- **/scripts**: Scripts Python/Playwright para automações.
- **/templates**: Templates de automações comuns (ex: Mercado Livre → Omie).
- **/docs**: Guias para clientes (ex: "Como gerar sua chave da API Omie").
- **/sandbox**: Ambiente de testes com Docker e dados fictícios.

## Exemplos
- **Mercado Livre → Omie**: Baixa pedidos, consulta estoque, gera relatório.
- **HubSpot → Omie**: Sincroniza leads e oportunidades.

## Como contribuir
1. Clone o repositório.
2. Crie um branch para sua automação.
3. Suba o script em `/scripts` ou o template em `/templates`.
4. Documente em `/docs`.
5. Teste na sandbox.
